# LAN Stream

Приложение для low-latency трансляции рабочего стола по локальной сети.

## Компоненты

- `source/` — Windows-приложение ПК-источника на Python;
- `server/` — HTTP/WebSocket signaling server;
- `client/` — браузерный WebRTC-клиент;
- `tests/` — тесты;
- `docs/` — документация.

Основной стек: WebRTC + H.264 + UDP.

## Быстрый запуск прототипа

1. Установить зависимости:

```text
pip install -r requirements.txt
```

2. Запустить сервер из корня репозитория:

```text
python -m server.app.main
```

Сервер слушает `0.0.0.0:8080`. Браузерный клиент доступен по адресу `http://<IP-сервера>:8080/`.

3. На ПК-источнике запустить:

```text
python -m source.app.main --server http://<IP-сервера>:8080 --name "Desktop"
```

4. Открыть адрес сервера в браузере и выбрать появившуюся трансляцию.

Прототип использует программный H.264 через media pipeline `aiortc`. Аппаратное кодирование и дальнейшая оптимизация CPU относятся к этапу 6.

## Диагностика

Источник пишет в лог CPU, RAM и фактическую частоту выдачи кадров. Браузер отображает состояние WebRTC, полученные кадры, bitrate/статистику и RTT, если браузер предоставляет соответствующие WebRTC stats.
